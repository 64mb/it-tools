# Local LLM model mirror

Runtime model files in this directory are generated by
`pnpm models:download`. They are pinned, text-only q4 artifacts from the
Apache-2.0 licensed Qwen3.5 ONNX repositories listed in
`src/tools/local-llm-playground/local-llm-model-assets.json`.

The multi-gigabyte generated revision directories and download manifest are
deliberately not tracked by Git. They must be present when publishing a build
that includes Local LLM Playground. Run `pnpm models:check` before deployment.
